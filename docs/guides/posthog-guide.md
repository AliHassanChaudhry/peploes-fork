# PostHog account selection

The approved Peploe's staging destination is EU project `229786`.
Its [saved reservation funnel](https://eu.posthog.com/project/229786/insights/r9xocEe2)
belongs to that staging project. Production needs a separate approved project;
access to staging is not approval to use it for live restaurant data.

The cross-provider owner decision is in the [analytics policy](ga4-guide.md).
