# Email approvals and manual recovery

Gina must approve final copy and restaurant routing. The mailbox owner must
approve the sender, Reply-To, restaurant inbox, staging recipients and SMTP
authentication method. Connector access in chat is not an application credential
or permission to send. Real inbox receipt, spam placement and domain identity
need external acceptance; provider acceptance alone cannot establish them.

For an uncertain notification, an operator must check provider evidence and the
approved inbox before authorizing any retry. Reconcile only the exact delivery
ID. If acceptance cannot be established, leave the outcome unknown and contact
the restaurant. A timeout is not evidence that nothing was delivered. This is
an operator decision, not permission for an agent to edit delivery records.
