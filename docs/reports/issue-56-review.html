Cause and correction

The homepage CSS replaced the desktop overlay with separate warm phone and burgundy tablet gradients. A production browser check reproduced those different rendered values before the fix.

The hero now shares the desktop colours, opacity stops and two gradient layers at every width. Below 1024px, the fade runs vertically behind the full-width copy; desktop retains its original angle. Image crops, layout and actions are unchanged by this fix.
