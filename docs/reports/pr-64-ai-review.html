1. Report theme: valid observation, P3 non-blocking

Original comment. The report fixes data-theme="dark" and defines a light palette but exposes no switch. Light printing exists separately. The site does not route or import this report.

The repository HTML guide requires a designed light alternative and describes controls when present. The installed readable-html-dossier skill explicitly permits omitting visible toggles unless interactive switching is required. A mandatory keyboard toggle is therefore not established by the cited policy. A native button with visible focus would be a small optional improvement, not a customer-site blocker.

2. Menu prefetch: valid cost, incomplete recommendation

Original comment. MenuNavigation lines 166 and 204 use full prefetch. The installed Next 16.4.2 Link guide says true fully prefetches dynamic routes; default null only prefetches to a loading boundary.

Menu loaders use connection() and per-render React memoization. The CMS provider disables CDN and uses cache: "no-store". Prefetch can therefore create additional server work and CMS reads for destinations a visitor never opens. Request counts, quota impact and real latency were not measured in this review.

The claim that all seven menu variants immediately prefetch is overstated: the default catalog has five direct links plus two collection buttons. Child links mount only after a collection opens. Viewport eligibility also limits mobile prefetch.

Issue #54 explicitly reports delayed menu switching. The new regression warms Dinner and Group Set Lunch, then delays subsequent RSC responses by three seconds while requiring the selected content within one second. Returning to automatic partial prefetch risks restoring this delay.

Recommendation: retain the deliberate prefetch behavior unless measurements justify a change. Measure production request/CMS load; then consider intent-based full prefetch or caching with an agreed freshness/invalidation policy. This is a P2 performance follow-up, not a demonstrated pre-merge defect.
